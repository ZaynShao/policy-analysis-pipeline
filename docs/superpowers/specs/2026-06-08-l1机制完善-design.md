**日期**:2026-06-08

**范围决策**:选项 C(见下)

## 目标

把 L1 采集机制层补到"能自主跑、无人工拐杖、无静默吞错",同时**与 B14 人工审核线对齐**:
本线负责"机器拿不准"项的**进池(IN)** + 采集质量逻辑;**人交互面 / 标准化回灌 / drain 交 B14**。

> "L1 机制彻底完善"分两半:本线能独立做完的是采集逻辑 + 进池 IN;池子的人交互/回灌那半
> 本质是 B14 接口,co-design,等 B14 盘完协议再接。本线不越界建交互面。

## 背景:本次暴露的真缺陷

1. **gate review_queue 静默丢**:`policy_gate` 在 LLM 解析失败 / conf < `REVIEW_THRESHOLD(0.7)`
   时 emit `action=review_queue`(docstring 自称"不静默丢"),但 `_gate_extracted_dir` 只有
   pass/commentary/reject 三桶 → review_queue 项无桶接、卡 ext/ 被后续清掉 = **实际静默丢**。
2. **fetch 失败静默**:抓取失败进 per-channel `ferr.txt`,无汇总(河北 swt.hebei 11 URL 全失败、无人知)。
3. **核验门 marker 太窄**:`_institution_match` 标记法 whack-a-mole → 真站(dgboc/zcom…)漏判候选
   → 逼出 CHECKPOINT 人工提升(本次靠人工绕过=滑坡苗头)。
4. **sweep 二元、discovery 候选**:无统一可见沉淀,散落各处。

## 架构

L1 流水线新增**一个 review pool 作"机器拿不准"项的统一沉淀**(只写不排,IN),
4 个生产者接进来;核验门改精度减入池;浅抓取健壮;文档对齐。

## 组件

### A · L1 review pool(新)
- **文件**:`state/l1_review/pool.jsonl`
- **模块**:`scripts/l1_collect/review_pool.py`
  - `append(entry: dict) -> bool`:按 `ref` 去重写入(已存在则跳过,返回 False)
  - `load() -> list[dict]` / `summarize() -> dict`(按 kind 计数,供收尾打印)
- **契约**(每条):
  ```
  {kind: "gate"|"checkpoint"|"sweep"|"fetch_fail",
   ref: <channel_id | pid | url>,
   reason: <str>, suggested_action: <str>,
   confidence: <float|null>, evidence: <str>,
   channel: <str>, run_label: <str>}
  ```
- **4 个生产者**:
  1. **gate**:`_gate_extracted_dir` 加第 4 路——`action=="review_queue"` 时把该 ext 项的 ref+证据
     写池(kind=gate),并把该 ext 文件移到一个 `review/` 暂存(不留 ext/ 被清)。返回值加 `n_review`。
  2. **discovery**:`discover_one` / `expand_channels_l1` 产候选(`ChannelStatus.候选`)时,append 池(kind=checkpoint)。
  3. **sweep**:`sweep_existing_commentary` 命中项写池(kind=sweep);`APPLY=1` 仍作过渡 drain。
  4. **fetch**:每渠道跑完,把 `{label}__ferr.txt` 的失败 URL 汇总 append 池(kind=fetch_fail,
     suggested_action 由重试结果定:retry_exhausted / body_too_short)。

### B · 核验门精度修(减入池)
- `_institution_match(domain, channel_type)` → 增 host 省份/口径校验:
  - target 已知期望省份(`commerce_market_targets` 带 `province`);从 resolved host 取省份信号
    (省拼音/缩写/gov 域省段,复用 `refdata` 省拼音表)。
  - **判定**:host 省份命中期望省 + 是 gov 域 → 过;marker 降为次级信号(命中加分,不命中不否决)。
  - national 目标(无 province)走原逻辑(跳过省份校验,如 known-domain skip)。
- **目标**:真站(dgboc.dg/zcom.zj/sxdofcom.shaanxi…)不再漏判;串味(conghua 从化/hq.mof 财政部)仍拒。
- 核验门 backlog 标 ✅已修。

### C · 抓取健壮(浅)
- `fetch_candidates` / `step4_fetch`:单 URL 失败 → 有限重试(1 次,可换 firecrawl 参数)。
- 仍失败 → 进池(kind=fetch_fail,见 A.4)。可见性由 pool summary 兜,**不静默**。
- **不做**:UA 轮换/代理/headless(深度反爬归服务线;backlog 记)。

### D · 文档
- 八步采集法 SOP 重写为纯 L1(把 Step4.5/5C/6.5/7/8 的加工逻辑剥离,标注"加工见 L2")。
- `docs/BACKLOG.md` 追加:**B15 B14 池接口**(L1 4 池的 IN 已建 + OUT 契约已定,消费者/交互等 B14)+ 深度反爬推后;核验门标 ✅。

## OUT 契约(人审完 → 系统要的结果)

> 池子不能只进不出(B14 警告的"僵尸池")。L1 定**每 kind 的裁决语义 + 回灌动作**(只有 L1 知道自己能
> apply 什么);跨池标准化信封 + 交互/传输 = B14。**本线不建消费者**(回灌 applier),过渡用现有 oneshots
> (promote_checkpoint / sweep APPLY,自己重判/硬编码、不读 verdict);本节是**文档化"将来正式回灌消费什么"**。

| kind | 裁决 verdict | L1 回灌 apply 动作 | 附带字段 |
|---|---|---|---|
| gate | `pass` / `commentary` / `reject` | 暂存 ext 项 → `policies/` / `commentaries/` / 弃 | 可选 `corrected_label` |
| checkpoint | `promote` / `drop` | channel 候选→验证 / 移除候选 | — |
| sweep | `confirm` / `keep` | git mv `policies/`↔`commentaries/` / 不动 | — |
| fetch_fail | `retry` / `unfetchable` / `drop` | 重入抓取队列 / 标 unfetchable / 跳过 | 可选 `retry_params` |

**OUT 记录格式(L1 端,B14 之后包标准信封)**:
```
{ref, kind, verdict, corrections?, reviewer, note, decided_run}
```

## 数据流

```
run_incremental(每渠道):
  scan → fetch(失败→重试→仍失败→pool[fetch_fail]) → extract
       → gate(pass→passed / commentary→comm / reject→quar / review_queue→pool[gate]) → ingest
  收尾:pool.summarize() 打印 + ferr 汇总
discovery(expand_channels_l1):候选 → pool[checkpoint]
sweep(oneshot):命中 → pool[sweep]（APPLY 仍可过渡 drain）
```

## 错误处理
- pool 写入包 try/except——pool 故障**绝不中断**渠道循环(沿用 `_ingest_commentary` 模式)。
- 按 `ref` 去重——重跑不胀池。
- review/ 暂存目录纳入 run 收尾清理白名单(同现有 *.jsonl 清理)。

## 测试(TDD + mock 网络,沿用 `tests/l1_collect/`)
- `review_pool`:append/去重/schema/summarize 单测。
- gate→pool:构造 conf<0.7 与 llm_parse_error,断言写池 + ext 不被清丢。
- 核验门 host 省份:dgboc.dg/zcom.zj/sxdofcom.shaanxi **过**;conghua/hq.mof/gsxt **拒**;national 跳过。
- fetch→pool:mock 抓取失败,断言重试后入池 + reason 正确。
- sweep→pool:命中写池;APPLY 仍移动。
- 回归:现有 105 测试全绿。

## 纪律
- §C:LLM 判定(gate/分类)不写 raw;池在派生层 `state/`。核验门=确定性,写 catalog(provenance)。
- dry-run before apply:sweep/discovery 的 apply(回灌)仍 dry-run 优先。
- 滑坡自审:核验门改的是**规则**(host 省份校验,非 per-domain 特例);池是**机制**(统一沉淀,非补丁)。
