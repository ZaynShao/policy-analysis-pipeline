## 关键设计 & 纪律

- **§C**:LLM 判定不写 `0_raw/`,池/review 全在 `state/` 派生层。终审确认 diff 零 `0_raw` 写入。
- **append-only**:raw 只追加;池按 ref 去重,重跑不胀。
- **dry-run before apply**:sweep/discovery 的回灌仍 dry-run 优先。
- **不打补丁(滑坡自审)**:核验门改的是**规则**(host 行政区,非 per-domain 特例);渠道目录 = source 配置非派生规则;CHECKPOINT 人工核 = 设计内机制。
- **与 B14 边界**:本线只做**进池 IN + 回灌契约**;人交互面 + 标准化回灌消费者 = B14。handoff:`docs/B14-handoff-L1源质量池-2026-06-08.md`。
