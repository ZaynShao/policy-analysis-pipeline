Task 3 · scoring 代码

Create: scoring.py · Test: test_scoring.py
确定性纯函数,规则源 scoring.yaml。重要性公式 + 行动分类 2×2 + D6 修正 + 门。 
def importance(s): return round(s.D1*.40 + s.D2*.40 + s.D3*.20)
def gate_passed_deep(imp, region_level):
    return imp >= 3 or region_level in ("国家","省")
  • 边界测试(公式取整 / 2×2 矩阵 / D6 前跳后降 / 门四象限) → 实现 → 通过 → commit

Task 4 · program_gate 代码

Task 6 · judge 代码

Create: judge.py · Test: test_judge.py
