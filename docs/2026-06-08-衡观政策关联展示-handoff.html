二、9 类关系语义 + 方向

关系是有向的：from —[relationType]→ to。在政策详情展示时，要分清「本政策是起点」还是「本政策是终点」，用对应的措辞（正向 / 反向）。

relationType含义（from → to）本政策=起点(from) 显示本政策=终点(to) 显示
derives_from省/市派生自国家级（追溯）派生自 →← 被…落地(landed_by)
supersedes显式废止废止 →← 被…废止(superseded_by)
iterates升级 / v2升级自 →← 被…升级(iterated_by)
extends范围扩展（试点 → 全国）扩展 →← 被…扩展(extended_by)
clarifies实施细则 / 操作指引细化 →← 被…细化(clarified_by)
cites_basis显式「作为制定依据」引用以…为依据 →← 被…引为依据(cited_as_basis_by)
references引用但不修改引用 →← 被…引用(referenced_by)
aligns_with不同部门同主题对齐（平行）对齐 ↔（对称，方向弱）
conflicts_with内容冲突（罕见）冲突 ↔（对称）

当前生产数据里出现 8 类（conflicts_with 暂为 0）。分布参考：aligns_with 412 · references 391 · cites_basis 147 · derives_from 83 · clarifies 72 · extends 15 · iterates 13 · supersedes 5。

三、查一条政策的「相关政策」

本政策既可能是某关系的起点、也可能是终点，所以要查两个方向并合并：

// 出边：本政策 → 别人
SELECT relationType, toPolicyId   AS otherId, confidence, evidence, 'out' AS dir
FROM "PolicySemanticRelation" WHERE fromPolicyId = :policyId
UNION ALL
// 入边：别人 → 本政策
SELECT relationType, fromPolicyId AS otherId, confidence, evidence, 'in'  AS dir
FROM "PolicySemanticRelation" WHERE toPolicyId   = :policyId;

再用 otherId 关联 Policy 取标题等；按 relationType 分组、confidence 降序展示。Prisma 侧也可用 fromPolicy / toPolicy relation 直接 include 关联政策。

四、建议 UI（政策详情「相关政策」区）

  • 政策详情页加一个「相关政策」区块，按 relationType 分组（如：废止/升级/派生/依据/引用/对齐 …）。
  • 每条显示：方向措辞（见第二节正/反向列）+ 对方政策标题（可点进对方政策）+ confidence（可做弱化/小字）+ evidence（默认折叠，点开看判定证据）。
  • 演进类（supersedes/iterates/extends/derives_from）信息量最高，建议靠前；aligns_with/references 量大，可折叠或分页。
  • 无相关政策时显示「暂无关联政策」。
